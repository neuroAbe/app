** DONE Prepare for Common Questions
*** Q: Why did you choose BLoC pattern?
    - Strict unidirectional data flow
    - Highly testable (events in, states out)
    - Scales well for complex apps
    - Industry standard in Flutter
    - Great IDE support and tooling

*** Q: Why Clean Architecture?
    - Separates concerns clearly
    - Business logic independent of UI
    - Easy to test each layer
    - Can swap database for API easily
    - Maintainable long-term

*** Q: How would you add API integration?
    - Create RemoteDataSource alongside LocalDataSource
    - Repository coordinates between both
    - Add network client (dio or http)
    - Implement caching strategy
    - No changes needed to UI or BLoC

*** Q: How would you handle offline sync?
    - Queue changes locally with timestamps
    - Sync when network available
    - Conflict resolution strategy
    - Optimistic UI updates
    - Background sync service

*** Q: Why SQLite vs other storage?
    - Relational data model fits use case
    - Complex queries possible
    - Proven reliability
    - Easy migration to server DB
    - Better than key-value for this data

*** Q: Why this specific app?
    - Researched Al-Graphy's business model
    - Social media marketing company needs this
    - Shows understanding of domain
    - Demonstrates practical Flutter skills
    - Directly relevant to your operations

* Troubleshooting Common Issues
** ISSUE: Flutter pub get fails
   #+BEGIN_SRC bash
   # Clear pub cache
   flutter pub cache repair

   # Try again
   flutter pub get
   #+END_SRC

** ISSUE: Build fails with Gradle error
   #+BEGIN_SRC bash
   # Clean gradle cache
   cd android
   ./gradlew clean
   cd ..

   # Rebuild
   flutter clean
   flutter pub get
   flutter build apk --release
   #+END_SRC

** ISSUE: App crashes on launch
   - Check ~flutter logs~ for error messages
   - Ensure device has Android 5.0+ (API 21+)
   - Try uninstalling and reinstalling

** ISSUE: Database errors
   - Uninstall app completely
   - Reinstall to reset database
   - Database recreates with seed data

** ISSUE: Charts not rendering
   - Pull to refresh the page
   - Check that seed data exists
   - Verify fl_chart package installed
